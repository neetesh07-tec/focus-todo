📝 To-Do List — Focus on What Matters

A clean and simple task management web app designed to help users organize tasks, track time, and stay productive.
Built using HTML, CSS, and JavaScript, with support for task persistence using browser storage.

🚀 Features

✔ Add new tasks
✔ Delete tasks
✔ Live task rendering (no refresh)
✔ Shows running task count
✔ Responsive UI layout
✔ Adaptive task cards (auto line-wrapping)
✔ Stores tasks in memory
✔ Smooth UX for input and actions

🛠 Tech Stack
Layer	Technology
Frontend	HTML5, CSS3, JavaScript
Styling	Custom CSS (Flex + Grid)
Data	JavaScript Array (local state)
Persistence (coming soon)	LocalStorage
Version Control	Git + GitHub

🎮 How to Use

Open the web app

Enter a task title

Click Create Task

View active tasks rendered below

Click Delete to remove a task
